# 玩法与数值参考

[返回首页](../README.md) · 适用 `0.4.1-experimental`

以下时间按游戏正常 **20 TPS** 换算。卡顿时实际体感时间可能变长。1 点生命值等于半颗心；百分比伤害是计算倍率，不是固定扣血。

## 共用操作

| 操作 | 效果 |
| --- | --- |
| R（可改键） | 根据主副手搭配选择副刀动作 |
| V | 保留拔刀剑本体的特殊移动；主手短刀可由突进衔接三连刺 |
| 长按右键 | 主手刀自带的普通 SA，遵循本体释放条件 |
| 长按 V | 满足该刀与本体要求时使用超级 SA |

本附属没有增加单双刀模式切换。装上对应搭配即可使用；双长刀跟斩是装备后的被动效果。主手短刀的普通左键改为自己的快攻链，本版没有把长刀所有 Shift 组合招式逐项重制为短刀专属动作。

## 双长刀

### 自动跟斩

主刀普通刀招命中后，延迟 **4 刻 / 0.2 秒**补一次副刀斩。伤害按主刀这次攻击的基础计算结果乘 **0.75**，不复制附魔额外伤害，也不读取副刀附魔来二次结算。同一动作对同一目标仅追加一次；主动爆发有自己的流程，不再叠加这套被动。

跟斩带独立副刀出刀、刀光和音效，不增加额外击退、击飞或硬直，不花费副刀自己的耐久和耀魂。延迟期间会复查目标和装备，换刀不能把旧攻击的成长收益转给新刀。

### R 连续爆发

顺序为：

**主斩 → 副斩 → 主斩 → 副斩 → 主斩 → 副斩 → 主斩 → 副斩 → 双刀齐斩 → 主 SA → 副 SA → 主 SA → 副 SA**。

| 阶段 | 相对启动时间 |
| --- | --- |
| 八次交替快斩 | 第 0、6、12、18、24、30、36、42 刻；间隔 0.3 秒 |
| 双刀齐斩 | 第 52 刻；同一刻分别结算两刀 |
| 四拍 SA | 第 56、60、64、68 刻；间隔 0.2 秒 |

总流程约 **3.4 秒**，冷却从启动时起算 **8 秒**。爆发中锁住双手装备，移动速度降低 **35%**，转向限制在启动方向左右各 **60°**，并提供免控。它不是完全原地定身；仅实际被击中的怪物会被短暂限制移动，未命中的周围怪物不会被一起锁住。

近战斩击试验范围约 **5 格**。攻击型 SA 初始伤害倍率为主刀 **65%**、副刀 **45%**；治疗、护盾等 SA 仍依各自技能执行。主刀 SA 正常扣费，爆发内副刀 SA 免其耐久、耀魂消耗。某拍不能释放 SA 时，会使用普通斩击兜底，不能保证每一把刀都显示四个同样的发射特效。

## 副手短刀招架

适用：**主长＋副短**，或**主短＋副短**。按 R 抬刀，招架窗口 **20 刻 / 1 秒**。

第一个实际造成受伤的有效近战 / 弹射物命中，伤害乘 **0.2**，触发环形反击并结束本次招架。环形范围约 **2.5 格**，基础伤害 **2 点**，带轻微击退；随后获得 **16 刻 / 0.8 秒**无敌。绕过无敌标签的特殊伤害不在该无敌保护范围内。

招架可处理侧面和背面的有效攻击，不要求荆棘、不要求站定。火焰、荆棘、自伤以及通常的环境伤害不触发反击。环形反击不额外结算副刀附魔，不消耗副刀资源。

招架成功后，在 **0.8 秒**内再点 R 可释放一次副刀普通 SA，按该刀正常规则扣费。一次成功招架只给一次尝试机会；不符合条件的尝试不会替你保留到之后继续按。超时、换装备、死亡或切换维度会取消追加 SA 的机会。

## 主手胁差与已识别小太刀

| 招式 | 输入 | 当前基础倍率 / 距离 |
| --- | --- | --- |
| 快斩 → 回斩 → 短刺 | 连续左键；最短间隔 4 刻 / 0.2 秒 | 44% → 44% → 55%；约 2.6 格 |
| 突进三连刺 | 本体 V 方向突进后，12 刻 / 0.6 秒内点一次左键 | 每刺 23%，共三刺；间隔 3 刻 / 0.15 秒；约 3 格 |
| 副长刀横斩 | 主短＋副长时按 R | 向前扇形，约 5 格；冷却 40 刻 / 2 秒 |

这些倍率参与本体的攻击属性、等级与目标防御计算，不能直接当成最终扣血。三连刺不会额外击退目标，完成后下一次左键可重新进入快斩链。R 横斩不会像双长刀爆发那样持续限制目标移动，也不额外消耗副长刀资源。

制作胁差与被识别的小太刀可以使用短刀体系；仅仅名字带「短刀」或模型较短，不足以自动识别。已识别的原生小太刀保留原模型比例，制作胁差才使用样板 **70%** 的缩放。

## 成型与成长

普通模具适合保留喜欢的外观与普通 SA，重新养成；高级模具适合把已有附魔、精炼与击杀积累带到新胁差。两种模具都完整返还样板刀，消耗模具一次。

高级复制不会复制耀魂、当前连招目标、临时战斗状态、成长分配的小数余量，也不会把两把刀连成同一个存档身份。新刀与原刀独立成长。复制的具体白名单以首页表格和源码为准，不是任意第三方数据的逐字克隆。

副刀实际参与目标命中后，符合条件的原有战斗击杀与耀魂收益分为 **70% / 30%**。没有参与的副刀不拿分成；普通加魂、资源消耗等不会被一概拆分。十分之一单位的余数保存在各自刀上，保存、重进与换手后继续累计。
