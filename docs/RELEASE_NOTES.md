# 拔刀剑双刀 0.4.1-experimental

双长刀提供连续输出，胁差提供招架、近身快攻与不同主副手搭配。新增操作只使用一个可改键的「副刀动作」键，默认 **R**。

## 可以玩什么

- **双长刀被动跟斩：**普通刀招命中后约 0.2 秒追加一次 75% 基础伤害的副刀斩，不增加击退。
- **双长刀一键爆发：**八次交替快斩 → 双刀齐斩 → 主副交替四拍 SA，带装备锁定、免控和实际命中目标的短暂移动限制。
- **副手胁差招架：**1 秒窗口，首个有效受击减伤 80%，自动环形反击并获得 0.8 秒无敌；成功后再按 R 可追加副刀普通 SA。
- **主手胁差快攻：**快斩、回斩、短刺；V 突进后及时左键可连续三刺。主短副长可按 R 释放前方横斩。
- **胁差制作与成长：**泥坯烧制模具，用长刀制作同款胁差并返还样板；高级模具继承已支持的附魔与养成数据。副刀参与命中后分得 30% 的相关战斗成长收益。
- **外观：**同侧错角挂载，主手短刀新增第一人称抬刀蓄力与抽刀斩出动作。

## 下载和安装

游玩使用 `slashblade-dual-wield-26.1.2-0.4.1-experimental.jar`，放入对应 Fabric 实例的 `mods`。

要求 **Minecraft 26.1.2、Java 25+、Fabric Loader 0.20.1+、SlashBlade: Refabricated 26.1.2-1.5.1-Resharped-2.0.5**，并安装拔刀剑本体前置 Fabric API 与 Forge Config API Port。

可选战斗兼容补丁单独安装，要求 **Twilight Forest 4.9.768、MixinExtras ≥0.5.5**；不需要这项补丁时，双刀附属不要求安装暮色。不要将源码 JAR 或测试探针装进游戏。
